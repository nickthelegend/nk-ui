# 🚀 NICKTHELEGEND UI

**Premium Expo React Native Component Library** — A shadcn-style copy-paste component system designed for Fintech and Web3, featuring a rich dark mode by default.

[![NPM Version](https://img.shields.io/npm/v/nickthelegend-ui.svg?style=flat-square&color=C47A2B)](https://www.npmjs.com/package/nickthelegend-ui)

## 🎯 Quickstart

Initialize the `nk-ui` structure in your Expo project. This installs the core theming, globals, and hooks directly into your application.

```bash
npx nickthelegend-ui init
```

Add components you need. You own the code—the components are copied directly into your `components/ui` folder for full customization.

```bash
npx nickthelegend-ui add balance-card
npx nickthelegend-ui add button
```

## ✨ Features
- **Dark Fintech Design System**: Pre-configured colors and globals matching the premium Airbills vibe.
- **Copy-Paste Philosophy**: You own the code. No buried node_modules dependencies holding you back.
- **Expo & React Native Ready**: Built seamlessly on top of React Native, Expo Router, Expo vector icons, and linear gradients.
- **Fintech First**: Includes hyper-specific components like `CryptoAmountInput`, `BankTransferForm`, and `TransactionRow`.

## 📦 Requirements
Ensure you have the required peer dependencies installed in your Expo project:
```bash
npx expo install expo-linear-gradient @react-navigation/native react-native-safe-area-context
```

## 🎨 Theme Configuration
Customize the themes at `theme/colors.ts` and `theme/globals.ts` after initialization!
