# 🚀 NICKTHELEGEND UI

**Premium Expo React Native Component Library** — A shadcn-style copy-paste component system designed for Fintech and Web3, featuring a rich dark mode by default.

## 🎯 Quickstart

Initialize the `nk-ui` structure in your Expo project:

```bash
npx nk-ui init
```

Add components you need:

```bash
npx nk-ui add button
npx nk-ui add balance-card
```

## ✨ Features
- **Dark Fintech Design System**: Pre-configured colors and globals matching the premium Airbills vibe.
- **Copy-Paste Philosophy**: You own the code. Edit the components directly inside your `components/ui` folder.
- **Expo & React Native Ready**: Built seamlessly on top of React Native and Expo vector icons, linear gradients, and layout.

## 📦 Requirements
Ensure you have `expo-linear-gradient` installed for the primary buttons and specific fintech cards.
```bash
npx expo install expo-linear-gradient
```

## 🎨 Theme Configuration
Customize the themes at `theme/colors.ts` and `theme/globals.ts`!
